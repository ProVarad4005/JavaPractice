# JavaLearning ☕

A personal repository dedicated to my independent, self-taught Java explorations and coding challenges. This space serves as a sandbox for experimenting with new concepts, testing logic, and solving practice problems outside of formal class coursework.

## 📂 Project Structure

This repository is organized into distinct packages based on the type of learning and practice:

* **`learn.varad.code`**
    Contains core Java concepts, syntax tests, and conceptual implementations as I learn them.
    *Examples: `RunCondition.java`, `TwoDArrays.java`*

* **`practice.varad.selftaught`**
    Dedicated to hands-on practice, logical problem-solving, and self-assigned coding challenges.
    *Examples: `Challenge1.java` through `Challenge7.java`*

## 🛠️ Tech Stack
* **Language:** Java (JavaSE-21)
* **Environment:** Eclipse IDE
* **Version Control:** Git & GitHub

## 🎯 Goals
- Reinforce theoretical concepts through practical application.
- Build a solid foundation in object-oriented programming, data structures, and algorithms.
- Maintain a clear separation between independent exploration and structured class assignments.
